# Estudo e Prática de NoSQL com MongoDB

Este repositório atua como um portfólio contínuo para registrar os conteúdos, anotações e atividades desenvolvidas na disciplina, com foco no estudo e prática do paradigma NoSQL.

### O que é NoSQL?
* NoSQL é um paradigma de banco de dados que engloba diversos tipos de bancos não relacionais.
* Estes bancos são projetados para oferecer flexibilidade, escalabilidade e alto desempenho.
* Existem quatro paradigmas principais de bancos NoSQL: orientados a documentos (ex.: MongoDB), chave-valor (ex.: Redis), famílias de colunas (ex.: Cassandra) e orientados a grafos (ex.: Neo4j).

# Desbravando o NoSQL com Projetos Práticos

Avançando na jornada de desenvolvimento de Sistemas de Informação, dominar novos paradigmas de armazenamento de dados é um passo fundamental. Enquanto a modelagem relacional tradicional (com a qual já estamos acostumados) atende a cenários estruturados, a flexibilidade, o alto desempenho e a escalabilidade dos bancos orientados a documentos abrem novas portas — especialmente para integrações futuras com aplicações web e arquiteturas robustas de backend.

### A Prática como Foco Central

A proposta deste repositório é estritamente **hands-on (mão na massa)**. Aqui, a teoria apresentada em sala de aula será imediatamente transformada em código, scripts e experimentações. Ao explorar os diretórios e arquivos, você encontrará:

- **Projetos de Orientação:** Cenários simulados do mundo real onde aplicaremos a modelagem de dados "schemaless", demonstrando quando e por que utilizar documentos incorporados ao invés de relações complexas.
- **Laboratórios de CRUD e Consultas:** Exercícios práticos detalhados envolvendo a criação, leitura, atualização e exclusão de dados, avançando gradativamente para consultas mais complexas dentro de coleções MongoDB.
- **Evolução Contínua e Versionamento:** Este repositório será atualizado continuamente, refletindo o aprofundamento técnico ao longo da disciplina e servindo como um guia de referência limpo, bem documentado e estruturado com boas práticas de Git e Markdown.
